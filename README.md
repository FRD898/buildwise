# Buildwise

Aplicación complementaria de la ruta "Product Builder con IA" de Netzun: donde vive el método que se construye en cada taller, versionado y expuesto al agente del alumno.

Qué es y qué no es: [`docs/product-brief.md`](docs/product-brief.md).

## Desarrollo

```bash
pnpm install
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev` — servidor de desarrollo
- `pnpm build` — build de producción
- `pnpm start` — servidor de producción
- `pnpm lint` — ESLint
